# Gemini Story App

This is an Android application that uses the Google Gemini API to generate short stories based on user-provided text or images.

## Features

- Generate stories from a text prompt.
- Generate stories from an image and a text prompt.
- Simple UI built with Jetpack Compose.

## Getting Started

### Prerequisites

- Android Studio
- An Android device or emulator
- A Google Gemini API key

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/gemini-story-app.git
   ```
2. Open the project in Android Studio.

### Configuration

1.  Create a `local.properties` file in the root of the project.
2.  Add your Gemini API key to the `local.properties` file:
    ```
    apiKey=YOUR_API_KEY
    ```

### Running the Application

1.  Build the project in Android Studio.
2.  Run the application on an Android device or emulator.
